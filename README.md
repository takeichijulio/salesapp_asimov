SallesApp – Asimov Academy

Sobre o projeto

O SallesApp é um aplicativo web desenvolvido em Python utilizando Streamlit, Pandas e Plotly. O objetivo do projeto é permitir a visualização, o controle e a análise de dados de vendas de filiais de forma interativa.

O aplicativo funciona como um visualizador de dados e também como um ambiente de simulação, permitindo a adição e remoção de registros de vendas. Os dados utilizados são gerados por funções em Python e não representam dados reais, tendo finalidade exclusivamente educacional.

Este projeto foi desenvolvido como parte do curso “Python para Usuários de Excel”, da Asimov Academy, no projeto prático SallesApp.

Instalação

Clone o repositório.

Crie um ambiente virtual na pasta do projeto.

Ative o ambiente virtual.

Instale as dependências listadas no arquivo requirements.txt.

Execução do aplicativo

Com o ambiente virtual ativado, execute o comando:

streamlit run Home.py

O aplicativo será iniciado e aberto automaticamente no navegador.

Funcionalidades

Visualização geral de dados de vendas
Tabelas dinâmicas para análise
Visualizações interativas de dados
Adição e remoção de linhas do banco de dados simulado
Navegação por múltiplas páginas
